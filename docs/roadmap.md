# Roadmap

AI Flow Pilot 的路线图按 30 天申请期设计，目标是从空壳原型推进到可演示的 MiMo Agent / Coding 评估工具。

## Week 1：原型与申请材料

- 完成项目 README、申请描述和使用证明材料。
- 搭建前端控制台骨架。
- 明确 Planner / Executor / Reviewer 的职责边界。
- 定义模型评估指标。

验收标准：

- GitHub 仓库可公开访问。
- 首页可本地启动并截图。
- 申请文案和路线图可直接提交或截图。

## Week 2：MiMo API 接入

- 增加后端代理，避免前端暴露 API Key。
- 支持配置 MiMo Base URL、模型名称和 API Key。
- 实现单轮任务调用。
- 保存基础调用日志。

验收标准：

- 可以通过 MiMo 创建一次 Planner 任务。
- 调用日志包含模型、耗时和 Token 估算。

## Week 3：Agent 流程闭环

- 实现任务创建和状态流转。
- 支持上传 PR diff、测试日志和项目规范。
- 实现 Planner / Executor / Reviewer 三阶段执行。
- 输出结构化审查报告。

验收标准：

- 可以完成一次代码审查任务闭环。
- 报告包含问题等级、影响范围和修复建议。

## Week 4：评估与证明

- 增加模型对比评估。
- 记录任务通过率、人工修正次数和 Token 成本。
- 生成可导出的评估报告。
- 整理 Demo 视频和截图。

验收标准：

- 至少完成三类任务评估：代码审查、需求拆解、文档生成。
- 输出 MiMo 与其他模型的对比表。
- 形成可补交的使用证明材料。
